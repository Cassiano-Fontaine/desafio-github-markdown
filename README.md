## Sobre o projeto

Este repositório foi criado para colocar em prática os conteúdos da formação de Git e GitHub da **[DIO](https://www.dio.me/)**.

O desafio envolve a criação de um repositório, o uso dos principais recursos do GitHub, a colaboração entre participantes e a formatação de arquivos utilizando Markdown.

Para realizar a atividade, convidei a Débora para colaborar comigo. Eu fiquei responsável pela documentação do projeto, enquanto ela vai trabalhar com a parte de colaboração no GitHub.

## Objetivos

1. **Criar um repositório no GitHub:**
   - Criar um repositório público chamado `desafio-github-markdown`.
   - Adicionar o arquivo `README.md`.
   - Utilizar o GitHub.dev para editar o projeto.

2. **Versionamento com Git:**
   - Clonar o repositório.
   - Realizar alterações nos arquivos.
   - Registrar as modificações utilizando commits.

3. **Colaboração:**
   - Adicionar uma colaboradora ao repositório.
   - Criar branches para trabalhar nas alterações.
   - Abrir Issues e Pull Requests.
   - Revisar as contribuições e realizar o merge.

4. **Formatação com Markdown:**
   - Editar e organizar o arquivo `README.md`.
   - Utilizar títulos, listas, links, divisórias e outros recursos do Markdown.
   - Documentar as atividades realizadas durante o desafio.
